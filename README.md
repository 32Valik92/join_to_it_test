# Calendar Test Task

Test task built with **React**, **TypeScript** and **Vite**.

The app is a calendar dashboard where users can create, edit, delete and drag events.

## Demo

**GitHub Pages:** [https://32valik92.github.io/join_to_it_test/](https://32valik92.github.io/join_to_it_test/)

## Tech Stack

*   React
*   TypeScript
*   Vite
*   Tailwind CSS
*   Redux Toolkit
*   FullCalendar
*   React Hook Form
*   Zod
*   date-fns
*   React Icons
*   ESLint
*   Prettier

## How to run locally

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/32Valik92/join_to_it_test](https://github.com/32Valik92/join_to_it_test)
   
2. **Navigate to the project directory:**
   ```bash
   cd join_to_it_test
3. **Install dependencies:**
   ```bash
    npm install
4. **Start the development server:**
5. ```bash
    npm run dev
6. **Open your browser and navigate to:**
7. ```bash
    http://localhost:5173
